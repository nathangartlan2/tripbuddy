# Mock Data Files

This directory contains JSON files with sample park data for development and testing purposes.

## Files:

- **parks.json** - Sample park records matching the `Park` entity schema
- **park-things-to-do.json** - Sample activities matching the `ParkThingToDo` entity schema

## Usage:

These files are used by the API during development to provide realistic data without requiring a database connection.

## Data Sources:

Sample data is based on real National Park Service information for:

- Voyageurs National Park (Minnesota)
- Yellowstone National Park
- Grand Canyon National Park
- Yosemite National Park
- Other major national parks

## Format:

JSON files follow the exact schema of the database entities to ensure seamless integration when transitioning to a real database.
